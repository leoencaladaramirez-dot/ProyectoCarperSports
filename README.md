# ⚽ CarperSports - Tienda de Artículos Deportivos

¡Bienvenido al repositorio oficial de **CarperSports**! Este proyecto es un sitio web E-Commerce ligero, moderno y responsivo, diseñado para la exhibición y venta de equipamiento deportivo al por mayor y menor con integración directa a pedidos por **WhatsApp**.

---

## 🎨 Paleta de Colores e Identidad Visual

El diseño visual está construido bajo una estética deportiva, moderna y de alto contraste:

* **Azul Marino / Navy (`#0b132b`, `#070a13`):** Fondo principal y elementos estructurales para un acabado elegante.
* **Azul Rey / Eléctrico (`#2563eb`):** Color primario para botones de acción, bordes activos y barras destacadas.
* **Azul Claro / Cyan (`#38bdf8`):** Detalles, etiquetas de productos y acentos de brillo.
* **Blanco (`#ffffff`):** Tipografía principal para máxima legibilidad.
* **Rojo Deportivo (`#dc2626`):** Badges de ofertas, contadores del carrito y botones de adición.

---

## ✨ Características Principales

* **Buscador en Tiempo Real:** Filtrado dinámico de productos por nombre o palabras clave mediante JavaScript.
* **Filtro por Categorías:** Clasificación rápida (Fútbol, Gimnasio, Accesorios).
* **Selector de Tallas / Medidas:** Opción integrada en cada producto para seleccionar medidas antes de agregar al carrito.
* **Carrito Deslizante (Modal):** Gestión de items, actualización de cantidades y cálculo automático del total.
* **Integración con WhatsApp API:** Generación de un mensaje con formato automático conteniendo el desglose detallado del pedido (productos, tallas, cantidades y total) para enviarlo al vendedor con un solo clic.
* **Prueba Social y Confianza:** Secciones integradas para testimonios de clientes, badges de garantía y datos de ubicación física.
* **Diseño 100% Responsivo:** Adaptado para dispositivos móviles, tablets y monitores de escritorio.
